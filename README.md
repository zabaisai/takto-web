# tehus-crm-web

Página web comercial (landing) de **Tehus CRM**.

Proyecto **independiente**: no forma parte ni depende del repositorio del CRM (`Tehus_Rattan`).

## Estado

Repositorio recién inicializado. **Todavía no hay código de la landing.**
La estructura actual solo está preparada para recibir el mockup definitivo aprobado.

## Reglas del proyecto

- No mezclar nunca este repositorio con el del CRM (`Tehus_Rattan`).
- No desplegar: sin VPS, DNS, staging, Meta, WhatsApp ni Caddy hasta nueva orden.
- El desarrollo de la landing empieza solo cuando se entregue el mockup definitivo.

## Estructura

```
mockup/          Mockup definitivo aprobado (HTML/imágenes/PDF/Figma export)
docs/            Notas, decisiones y requisitos
src/             Código fuente de la landing (vacío por ahora)
public/          Estáticos: imágenes, iconos, fuentes (vacío por ahora)
```

## Siguientes pasos

1. Adjuntar el mockup definitivo en `mockup/`.
2. Definir stack a partir del mockup.
3. Implementar la landing.
4. Despliegue (pendiente de autorización explícita).
